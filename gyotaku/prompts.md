# 魚拓アイコン16種 — チャッピー（ChatGPT）用プロンプト

釣果予報ツールの「漢字の札」を、魚拓風のアイコンに差し替えるための絵。
**4枚に分けて、1枚に4匹（2×2）ずつ**描いてもらう。1枚にまとめると絵柄がそろい、こちらで切り分ける。

## 共通の指定（4枚とも、この文を先頭に付ける）

```
魚拓（ぎょたく）風のアイコン素材を作ってください。
・本物の魚に墨を塗って和紙に写し取ったような、白黒の魚拓。墨のかすれ・ウロコやヒレの筋が少し残る質感。
・背景は無地の白（和紙の質感は薄く、ほぼ白）。文字・落款・ハンコ・枠線は入れない。
・正方形の画像を2×2の4マスに分け、1マスに1匹ずつ、魚は左向き・横向き全身で、マスの中央に大きめに。
・マスとマスの間は余白を十分に空け、魚同士が重ならないように。
・小さく表示（約50px）しても何の魚か分かるよう、その魚らしい形（体型・ヒレ・口・尾）をはっきり。
・4匹とも同じ墨の濃さ・同じ線の太さで、絵柄をそろえる。
```

## 1枚目
```
左上：アオリイカ（胴が丸く、胴の縁にぐるりとヒレがある。足は短め）
右上：ブリ（紡錘形で大きく、尾びれが深く二股）
左下：サゴシ（細長い若いサワラ。背中に小さなヒレが並ぶ）
右下：カサゴ（頭が大きくトゲトゲ、口が大きい根魚）
```
