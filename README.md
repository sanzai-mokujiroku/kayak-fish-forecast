# カヤック釣果予報

釣行前に、**水温・潮・天気から「狙いの魚種が釣れそうか」**を◎○△×で判定する簡易ツール。富山湾向けだが現在地取得で全国対応。`kayak-go-check`（出艇判断）の姉妹アプリ。

## 使い方
- ブラウザで `index.html` を開く（PWA・ホーム画面に追加可）
- 現在地を取得 → 最寄りの潮汐観測点を自動選択
- 今日／明日／明後日を切り替えて、魚種ごとの「釣れそう度」を確認

## 対象魚種（v1）
🦑 アオリイカ ／ 🐟 青物（ブリ・ハマチ） ／ 🐡 根魚（キジハタ・カサゴ） ／ 🐠 フラット（ヒラメ・マゴチ）

## 判定に使っている条件
| 要素 | 内容 | データ元 |
|---|---|---|
| 水温 | 日中平均の海面水温を魚種の適水温と照合 | Open-Meteo Marine API (`sea_surface_temperature`) |
| 季節 | 月ごとの旬スコア（回遊・産卵期） | 内蔵ルール |
| 潮 | 大潮/中潮/小潮の潮回り × その時間帯の潮の動き（満干の中間で最大） | tide736.net |
| 時合 | 朝マズメ・夕マズメ・日中（日の出/日の入から算出） | Open-Meteo (`sunrise/sunset`) |
| 天気 | 気圧（低気圧接近で活性↑）・降水（濁り。澄み好み/ササ濁り好みで加減） | Open-Meteo (`pressure_msl`, `precipitation`) |
| 安全 | 風速・波高・雷で GO/CAUTION/STOP（出艇可否の目安、go-checkと同基準） | Open-Meteo |

魚種ごとに上記を重み付き合算し、**1時間刻みで「釣れそう度(0-100点)」を全時間帯ぶん算出**。
- 各魚種カードに**時間帯別スコアの横スクロール表**（色分け・ピークに枠）を表示 → 早朝や夜に行けない人でも、行ける時間の点数で狙いを選べる
- カード見出しはその日の**ピーク点**と◎○△×
- 時合モデル：朝マズメ・夕マズメを鋭いピーク（日の出/日の入基準のガウス）、日中はベース、夜は魚種次第（根魚は高め）

## 判定ロジックの調整
`index.html` 内の `SPECIES` 配列を編集すれば、適水温・旬・潮の好み・重みを魚種ごとに変えられる。
将来は `kayak-fishing-log` の実釣データを取り込んで補正する予定（ルール→学習）。

## データ元・謝辞
- 気象・海象：[Open-Meteo](https://open-meteo.com/)（CC BY 4.0）
- 潮汐：[tide736.net](https://tide736.net/)（気象庁 潮位表をもとに算出）
- 潮汐観測点データ（`stations.js`）は `kayak-go-check` から流用

## 注意
「釣れそう度」の目安であり、当日のベイト・地形・運の要素は大きい。**海に出られるかの安全判断は必ず出艇判断チェック・現地確認と合わせて自己責任で。**
